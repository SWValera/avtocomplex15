## Файлы сайта

## Размещение

Скопируйте файлы сайта из корня репозитория в корень сайта на выбранном хостинге, сохранив папку `assets` и скрытый файл `.htaccess`. Подключите домен и HTTPS. Для статического хостинга используйте корень репозитория как каталог публикации, без этапа сборки.

Файл `.htaccess` содержит правила для Apache. Другие серверы и платформы требуют своих настроек перенаправлений. Загрузка исходников в GitHub сама по себе не подключает домен и не публикует сайт на хостинге.
