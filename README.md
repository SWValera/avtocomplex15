## Размещение

Рабочая публикация связана с веткой `main` этого репозитория через **Cloudflare Workers Builds**, сервис `avtocomplex15`. Это подтверждено GitHub check run `Workers Builds: avtocomplex15`; проект не является Cloudflare Pages. Сборка интерфейса не нужна. Существующая интеграция запускает Wrangler после обновления `main`.

`wrangler.jsonc` задаёт тот же Worker, обработчик `seo-worker.mjs` и статические файлы в корне. `.assetsignore` разрешает загрузку только файлов сайта, исключая исходник Worker, документацию, тесты, Git и `.htaccess`. Привязки доменов и DNS управляются в Cloudflare; конфигурация не перезаписывает их. Файл `.htaccess` оставлен для возможного размещения на Apache, на Cloudflare он не исполняется.

Проверка перед публикацией: `node --test tests/seo-worker.test.mjs`, затем `npx wrangler deploy --dry-run`. Локальный просмотр с реальным поведением Cloudflare Assets: `npx wrangler dev`. После push необходимо дождаться успешного GitHub check run и проверить сам домен.

Резервная точка перед SEO-изменениями от 23.10.2026: ветка `backup/pre-google-seo-2026-10-23`, commit `a50e9e6fab7cbc8b93225ea918f1547922b9f8e4`. Для отката используйте `git revert` соответствующего SEO-коммита и обычную публикацию, без принудительной перезаписи истории.

## SEO

Canonical, Open Graph, JSON-LD, robots.txt и sitemap.xml используют https://avtocomplex15.kz/. Sitemap содержит одну страницу; дата `lastmod` соответствует фактическому изменению содержимого, её нельзя обновлять автоматически при каждой сборке.

Worker объединяет нормализацию HTTP/HTTPS, www и старых адресов в один 301. `/home` и `/geometry` (также варианты с завершающим слешем) переходят на `/`, поскольку это старая главная и соответствующая услуга. `/index` и `/index.html` также переходят на `/`. Другие отсутствующие адреса возвращают 404 с `404.html`; нельзя включать SPA fallback или перенаправлять все старые услуги на главную. 23.10.2026 основной домен и www.avtocomplex15.kz подтверждены как Custom Domains действующего Worker. Для www добавлена привязка через Cloudflare API; DNS и HTTPS проверены. Оба варианта www возвращают один 301 на https://avtocomplex15.kz/. Эти привязки управляются в Cloudflare и сохраняются при публикации без поля routes в wrangler.jsonc.

Стили и интерфейсный скрипт кэшируются на час, изображения — на сутки. При изменении `style.css` обновляйте параметр версии в обеих HTML-страницах. HTML и SEO-файлы сохраняют обязательную проверку свежести. Настройки и скрипты Яндекс.Метрики не менялись.

Отправка sitemap и запрос переиндексации требуют авторизованного Google Search Console. Публикация файлов сайта сама по себе не выполняет эти операции. Не используйте Google Indexing API для этого сайта и не применяйте Change of Address при сохранении домена.
